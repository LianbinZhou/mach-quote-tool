# Mach Quote Tool（机加工报价计算器）

⚠️ 注意：`vendor/mach-calculators` 依赖未声明开源协议（npm 上 license 字段为空），**仅供本地使用，请勿将该依赖部分再分发**。本仓库自身代码为 MIT 协议。

## 这是什么

把 `@usethink/mach-calculators` 公式库封装成**双击就能用的网页工具**，为机加工（CNC 车/铣、线割、放电、磨床等）行业做快速报价：

1. **加工费计算**：各工序工时 × 设备费率
2. **材料费计算**：毛坯（方料/圆棒/圆管）体积 × 密度 × 单价
3. **综合报价**：(加工费 + 材料费) × 复杂程度 × 精度 × 表面 × 批量 × (1 + 利润率) × (1 + 税率)

## 怎么用

### 普通用户

直接双击 `dist/index.html`，浏览器打开即用，**无需联网、无需安装任何东西**。

### 开发者

```bash
npm install          # 安装构建工具（esbuild）
npm run build        # 构建，产物在 dist/index.html
```

## 公式来源

报价公式源自台湾风格《加工件费用计算表》的乘数体系：

```
综合报价 = (加工费 + 材料费) × K1 × K2 × K3 × K4 × (1 + 利润率) × (1 + 税率)
K1 = 复杂程度系数（1.0 ~ 2.0）
K2 = 精度等级系数（1.0 ~ 1.6）
K3 = 表面粗糙度系数（1.0 ~ 1.8）
K4 = 批量系数（0.85 ~ 2.0）
```
